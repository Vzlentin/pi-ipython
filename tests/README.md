# Verification

`npm test` is model-free. It runs typechecking and real kernels.

- `test_output.mjs` checks that the copied output truncation in `core/output.ts` cuts output exactly like Pi's `truncateTail`: final newlines, line and byte limits, lines that fill the byte limit exactly, and cuts inside multi-byte characters. It also checks ANSI stripping on CSI, OSC and incomplete sequences.
- `test_kernel.mjs` covers cross-cell state, per-cell working directories, expression evaluation, synchronous and asynchronous interruption, evaluate timeouts, SIGINT-resistant fallback kills, one-shot reset reporting, output overflow, process-group cleanup, and the `ipython:kernel-starting` contract, including runtime startup code that runs after the listener's, `hs` on start and restart, the pyarrow, BigQuery, db-dtypes and matplotlib imports in a new kernel, and figures as PNGs in display order with no `<Figure` text, no matplotlib or BigQuery import at start, the inline backend over a listener `MPLBACKEND`, `clear_output` that clears images, and six figures that keep four and count two as dropped.
- `test_headstart.mjs` runs the nine `headstart` verbs in a real kernel: `dir(hs)` equal to the verbs of the card in the tool description, a jsonl file with a bad line, leading-zero codes in xlsx and csv, other sheet names, json, toml and records input, `sheet` refused outside workbooks, refused text, unsupported suffixes and non-frame data for csv, jsonl, xlsx and parquet, a plain list kept as a json value, an empty frame in xlsx, the xlsx frozen header, filter and column widths, one sheet per key, no index column, json and jsonl round trips, a parquet round trip with mixed types and no index column, `montre` returning its input, cutting long frames and text, and showing a last-line view once, `combien` counts with NaN, share, two keys and records, and a required key, and `compare` with only a, only b, changed, equal and NaN-against-NaN rows, `joins` with the matched, only a and only b counts on records, a refused left or inner join that repeats a key of b and names only that key, and `validate=` that returns the merge, also with more rows, `decris` with the missing share, distinct count, top values, min and max of number, text, mixed and nested array columns, a category column with an unused category, and equal profiles from a frame and its records, `verifie` with all checks passing and returning `None`, a Series check refused before any check runs, and two failed checks that print every result before one `AssertionError` names both, and `interroge` on a fake BigQuery client: a missing environment refused before any client, no cap printing only the type and estimate after a dry run, an estimate above the cap refused with no run, a run within the cap billed at most the cap, and an interrupt that cancels the job.
- `test_protocol.mjs` runs the runtime against a fake bridge process: an invalid `ready` fails startup at once, an invalid `result` fails the running cell instead of hanging, the next start reports the reset, and the images past the byte limit and the count limit are dropped and counted while the cell succeeds.
- `test_provision.mjs` removes a locked package from the Python environment and checks that two kernels starting at the same time sync it again and keep a package that is not in `core/uv.lock`, that an environment equal to `core/uv.lock` starts without provisioning, and that a start without `uv` on `PATH` fails with the spawn error and recovers when `uv` is back, that a sync that uv cannot do offline fails with uv's own error and recovers, and that a cancel during the sync reports a cancellation and recovers. It changes the `core/.python` of the clone while it runs, and the sync gets xlsxwriter from the uv cache, or from the network when the cache does not have it.
- `test_cells.mjs` covers the Herdr console lifecycle and extension wiring.
- `test_persistence.mjs` covers owner SIGKILL during startup, a quiet cell, a blocked checkpoint save, stalled bridge cleanup, and a stalled launch before Jupyter records the child, normal shutdown flushing a delayed save, namespace round trips, `hs` not saved and kept after a restore, live function globals, classes, module aliases, deletion, content deduplication, LRU garbage collection with shared blobs, strict checkpoint IDs, symlink refusal, ownership modes, linked cache bases, both opt-outs, and a clear error for a malformed `.pi/pi-ipython.json`.
- `test_branches.mjs` drives the extension through Pi's real `SessionManager`: edited prompts, branches before any cell, later leaves, copied `/fork` history, evicted-checkpoint fallback, retry after a cancelled restore, crash recovery, failed saves, no-op synchronization on the current branch, and cells that a codemode script runs as nested tool calls: structured results, Python exceptions as data, cancellation and crash recovery inside a script, and reset notices in the script's result. It also checks that a figure reaches the model as PNG image content after the text, that a cell with six figures sends four and names the two it did not send in a text part after the images, and that a text cell has no image content.
- `test_durable.mjs` drives the pi-durable tool through a real Harness on SQLite with a faux model: state across cells, `hs` in a tool cell, Python exceptions as error results, a kernel crash and the restore after it, a reopened store that restores from the conversation's entries, a fork that restores the state at its fork entry, long output that keeps its tail and names the file with all of it, cells that another tool runs through `executeTool` with the `CellResult` as structured output, a figure as PNG image content after the text, and the cell-start, cell-end and kernel-starting events on the host bus.
- `test_checkpoint_limits.mjs` covers protocol-5 buffers, nested and rebound functions, live-resource refusal, 64 MiB value and 256 MiB cell limits, content-addressed disk use, recovery after a hung restore, deletion of an unpickler that ignores interrupts after it kills the kernel, and three such values exhausting the restore attempts while the next cell is still checkpointed.

A missing extension-owned interpreter is provisioned through `uv` by the first kernel test. `npm run test:persistence` runs the three persistence-focused files.

Do not add tests that match source strings, pin method names, import spellings, or merely restate compiler success. Test public boundaries with independent inputs and observable failure recovery.
